## The project: Campus Assistant
A chatbot that answers student questions about college regulations using only official documents. Every answer cites the college, document and page. If the documents do not cover the question, it declines and suggests contacting the college office.

Built entirely on open-weight models: Gemma 4 for answers and all-MiniLM-L6-v2 for search.
